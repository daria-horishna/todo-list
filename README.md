# ToDo List

Простий веб-додаток для керування списком справ.

## Функціональність

- ➕ Додавання завдань
- ✅ Позначення завдань виконаними
- 🗑 Видалення завдань
- 💾 Збереження завдань у файлі `tasks.json`

## Технології

- HTML
- CSS
- JavaScript
- Node.js
- Express

## Запуск

Клонувати репозиторій:

```bash
git clone https://github.com/daria-horishna/todo-list.git
```

Перейти в папку проєкту:

```bash
cd todo-list
```

Встановити залежності:

```bash
npm install
```

Запустити сервер:

```bash
npm start
```

Відкрити:

```
http://localhost:3000
```
